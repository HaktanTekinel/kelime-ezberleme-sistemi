# Backend

Bu klasör, kelime ezberleme sistemi projesinin FastAPI tabanlı backend kodlarını içerir.

Backend tarafında kullanıcı işlemleri, kimlik doğrulama, kelime ekleme/listeleme ve veritabanı bağlantısı yönetilir.

## Kullanılan Teknolojiler

- Python
- FastAPI
- Uvicorn
- SQLAlchemy
- PostgreSQL
- Pydantic
- Passlib / bcrypt
- python-dotenv
